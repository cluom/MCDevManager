## Context

MCDevManager 是 Kotlin Multiplatform/Compose 客户端，Windows 发行形式为免安装 ZIP 和 MSI。Windows 系统小组件需要带包身份的独立提供程序和 COM 激活；主客户端退出时不能依赖 JVM 常驻。数据追踪页的普通/联机大厅日详情接口返回按日期、模组分组的指标；首页总览另有独立接口。

## Goals / Non-Goals

**Goals:** 主客户端退出后手动刷新；三个可重复添加的定义；独立账号/平台/模组/天数/指标配置；同时展示多个指标；保持业务字段和日期口径；会话及缓存安全保存；可打包安装并可回滚。

**Non-Goals:** 不承诺准确的定时后台刷新；不新增云服务器；不修改 iOS 组件；不将跨模组日活伪装成去重人数；不把暂无数据补为零；不对统计收入套分账权重。

## Decisions

1. 使用 .NET 8 + Windows App SDK 的独立 C# COM 提供程序，注册为 MSIX。替代方案是主程序常驻或网页组件：前者不满足退出后使用，后者增加服务器和认证边界。
2. UI 使用 Adaptive Cards；指标 `Input.ChoiceSet` 多选并独立保存。宿主可能将多选紧凑选择器呈现为复选列表，因此配置页面采用“展开多选”作为兼容降级，不承诺原生收起式多选外观。图表绘制为本地生成的 PNG data URI；不上传账号数据。
3. 按用户补充要求，同一组件内多个指标使用同一张图、多条不同颜色折线。相同单位使用原值共同刻度；混合单位将每条线除以该线周期内最大绝对值并乘 100，明确标注“相对趋势（各线峰值=100）”，图例保留原始数值、单位和峰值。全零序列仍为零，缺失值仍断开，避免无提示地混用钻石和人数数值。
4. 平台对应 `pe`、`comp`、`lobby`；普通列表过滤从未上线与 `pri_type=9`，联机大厅按数据追踪页商品 IID 列表查询。图表默认最近 14 个完整日期，结束日期为昨日，允许 7/14/30/60/90 天。
5. 合计仅对可累加字段求和；日活标注“模组日活合计（未去重）”。退款率仅在单模组时开放；账号合计不平均比率。不存在的指标或日期输出缺口，不默认零。
6. 登录会话由 Kotlin 桥接经标准输入传入提供程序工具模式，用 Windows DPAPI CurrentUser 加密后持久化。账号快照只含 ID、显示名、Cookie，绝不包含密码；命令行、日志和 CustomState 不保存 Cookie。账号删除与注销通过快照/撤销同步。
7. 手动刷新立即显示“正在刷新”，同一实例合并正在执行的请求；无冷却期。配置代次与会话指纹控制结果发布，旧账号/旧配置响应不得覆盖新页面。主应用未启动只读缓存；失效会话要求重新登录。
8. 缓存本地加密，按实例及配置隔离；刷新失败展示缓存日期与失败提示，不改写为成功或当天数据。日志仅包含操作、HTTP 状态、耗时、请求数量等无敏感诊断。

## Risks / Trade-offs

- Windows 宿主支持与包注册要求 → 编译、核心测试、MSIX 构建和宿主添加分别验收；缺少宿主实测不能声称已通过。
- 本机未安装 .NET SDK → 使用独立目录的 SDK，不改系统 PATH；正式提供程序自包含发布。
- MSIX 自签证书需要信任 → 不静默导入信任证书，保留安装步骤和明确授权暂停点。
- Win+W 分发限制 → 微软 Widgets 示例要求侧载启用开发者模式，另一分发途径是微软商店。自签 MSIX 安装成功不能当作免开发者模式发现/添加通过；当前用户拒绝开启且添加列表缺失，宿主验收暂停，未经授权不启用开关、不发布商店、不替换成桌面悬浮窗。
- 卡片固定高度与多指标 → 同图彩色多线和紧凑图例；不通过翻页冒充同时显示。
- 登录会话失效及账号切换 → 加密快照、撤销、请求前后指纹检查、缓存隔离。

## Migration Plan

新增组件安装包不覆盖现有桌面程序。先构建、测试与验证清单，再安装提供程序、启动更新后的桌面客户端同步会话，最后在 Win+W 添加三个组件并验收主程序退出后的刷新。卸载组件包不删除主客户端数据库；回滚桌面桥接不影响原登录。撤销共享可通过工具模式清除加密快照。

## Open Questions

系统宿主对紧凑多选、PNG data URI 和大尺寸高度的实际表现需在本机验证；签名证书信任与最终安装需要用户参与。
